# Watch Party Diagnostic & Migration Scripts

This folder contains scripts used to debug, test, and migrate data for the Watch Party backend, specifically related to the Backblaze B2 streaming and Cloudflare Worker proxy integration.

## Files Included

### 1. `fix_cdn_urls.py`
**Purpose:** Batch updates the `cdn_url` for existing `StorageProvider` records in the database.
**Usage:**
```bash
cd backend
python ../scripts/fix_cdn_urls.py
```
**Details:** This script fetches all storage providers from the database, applies the Cloudflare Worker URL (`https://billowing-king-8e25.nayandg8.workers.dev`) as a prefix to the `endpoint_url`, and saves the updated `cdn_url` back to the database. This was necessary to ensure all old providers route their binary streams through the zero-egress Cloudflare Worker proxy.

### 2. `fix_endpoints.py`
**Purpose:** Fixes malformed `endpoint_url` values in the database (e.g., missing `https://` prefix).
**Usage:**
```bash
cd backend
python ../scripts/fix_endpoints.py
```
**Details:** The Cloudflare Worker and `boto3` expect the endpoint URL to have a valid scheme (`https://`). This script scans the database for any endpoints missing the scheme and corrects them, preventing `400 Bad Request` errors caused by malformed presigned URLs.

### 3. `test_worker.py`
**Purpose:** Diagnostics script to verify the Cloudflare Worker proxy is correctly passing authentication headers and that Backblaze B2 accepts the generated presigned URLs.
**Usage:**
```bash
python scripts/test_worker.py
```
**Details:** Logs into the API using Supabase credentials, requests a streaming URL for a movie's poster image, and makes two requests:
1. **Direct to B2:** To verify the `X-Amz-Signature` generated by `boto3` is actually valid.
2. **Via Cloudflare Worker:** To verify the proxy correctly strips `Host` and other interfering headers before passing the request to B2.

## Context
These scripts were created to debug and resolve an issue where streaming `.ts` segments and images through the custom Cloudflare Worker resulted in `400 Bad Request` or signature mismatch errors from Backblaze B2. The final resolution required enforcing path-style S3 addressing in `boto3` and ensuring the `.m3u8` manifest always uses the backend proxy (for segment rewriting) while the actual binary blobs route through the Cloudflare Worker.
